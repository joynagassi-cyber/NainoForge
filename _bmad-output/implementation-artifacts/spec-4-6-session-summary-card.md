## Intent

**Problem:** Après une session d'apprentissage ou d'imprent, l'utilisateur a besoin d'un résumé visuel de ce qui a été accompli. Le Session Summary Card affiche les métriques clés : coverage (couverture), coherence (cohérence), depth (profondeur), et éventuellement le Cran final et l'IQS.

**Approach:** Créer un composant `SessionSummaryCard` qui:
- Affiche des indicateurs métriques (coverage, coherence, depth) sous forme de jauges ou de chiffres
- Inclut le Cran final avec le Confidence Marker
- Peut afficher un résumé textuel des points forts/faibles du session
- Suit le design system NainoForge

## Boundaries & Constraints

**Always:** Le card doit respecter le design system de NainoForge (palette, formes, elevation). Il doit être lisible et concis.

**Block Si:** Les métriques de coverage/coherence/depth nécessitent une analyse réelle du contenu. Pour MVP, utiliser des valeurs démo ou calculées de manière simplifiée.

**Never:** Ne pas ajouter de dépendances externes. Ne pas modifier l'architecture existante.

## I/O & Edge-Case Matrix

| Scenario | Input / State | Expected Output / Behavior | Error Handling |
|----------|--------------|---------------------------|----------------|
| HAPPY_PATH | Le card reçoit des métriques valides (coverage: 85, coherence: 0.8, depth: 3) | Le card affiche les jauges et le Cran avec les valeurs correctes | Aucun erreur attendu |
| ERROR_CASE | Des métriques sont manquantes ou invalides | Le card affiche des valeurs par défaut ou un message d'information | Logging silencieux |
